# 教务办·智能体 — 部署与更新教程

## 整体架构

```
┌──────────────────────────────────────────────┐
│  GitHub 仓库 (cmj4088/TAO)                    │
│                                              │
│  ┌─────────────┐    ┌───────────────────┐    │
│  │ GitHub       │    │ GitHub Container  │    │
│  │ Releases     │    │ Registry (GHCR)   │    │
│  │ 存放 .exe    │    │ 存放 Docker 镜像   │    │
│  └──────┬───────┘    └────────┬──────────┘    │
└─────────┼─────────────────────┼──────────────┘
          │                     │
          ▼                     ▼
   ┌──────────────┐    ┌──────────────┐
   │ 用户电脑      │    │ 服务器        │
   │ electron-    │    │ watchtower   │
   │ updater      │    │ 自动拉取镜像  │
   │ 自动检测更新  │    │              │
   └──────────────┘    └──────────────┘
```

## 前置要求

### 用户端（前端）
- Windows 10/11 系统
- 无需安装任何额外软件，安装包自带一切

### 服务器端（后端）
- 一台能跑 Docker 的服务器（Linux/Windows 均可）
- 安装 Docker 和 Docker Compose
