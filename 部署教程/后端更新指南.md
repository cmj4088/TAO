# 后端更新指南

## 工作原理

```
开发者推送代码 → GitHub Actions 自动构建 Docker 镜像 → 推送到 GHCR
                                                              │
                                                              ▼
                                                    服务器上的 watchtower
                                                    每 5 分钟检查一次
                                                    发现新镜像 → 自动拉取重启
```

## 首次部署（服务器上操作）

### 1. 安装 Docker

**Linux (Ubuntu/Debian):**
```bash
curl -fsSL https://get.docker.com | bash
sudo apt install docker-compose-plugin
```

**Windows:**
下载安装 Docker Desktop: https://www.docker.com/products/docker-desktop/

### 2. 登录 GitHub Container Registry

需要在 GitHub 上创建一个 **Personal Access Token (classic)**：
1. 去 https://github.com/settings/tokens
2. 点击 "Generate new token" → "Generate new token (classic)"
3. 勾选 `read:packages` 权限
4. 生成后复制 token

在服务器上登录：
```bash
echo "你的TOKEN" | docker login ghcr.io -u cmj4088 --password-stdin
```

### 3. 创建部署目录

```bash
mkdir -p ~/tao-backend/data
cd ~/tao-backend
```

### 4. 下载 docker-compose.yml

从仓库复制 `backend/docker-compose.yml` 到 `~/tao-backend/docker-compose.yml`。

或者直接在服务器上创建：
```bash
cat > docker-compose.yml << 'EOF'
services:
  backend:
    image: ghcr.io/cmj4088/tao-backend:latest
    ports:
      - "8002:8002"
    volumes:
      - ./data:/app/data
    restart: unless-stopped
    labels:
      - "com.centurylinklabs.watchtower.enable=true"

  watchtower:
    image: containrrr/watchtower
    volumes:
      - /var/run/docker.sock:/var/run/docker.sock
    command: --interval 300 --label-enable
    restart: unless-stopped
EOF
```

### 5. 启动

```bash
docker compose up -d
```

首次启动会自动从 GHCR 拉取镜像。

### 6. 验证

```bash
# 查看容器状态
docker compose ps

# 查看日志
docker compose logs -f backend

# 测试接口
curl http://localhost:8002/api/version
```

应该返回：`{"version":"0.1.0"}`

## 日常更新（全自动）

**不需要任何手动操作。**

watchtower 每 5 分钟检查一次 GHCR 上有没有新镜像，有就自动拉取并重启容器。

整个流程：
1. 开发者 push 代码到 GitHub
2. GitHub Actions 构建新 Docker 镜像，推到 GHCR
3. 5 分钟内 watchtower 检测到新镜像
4. 自动拉取 → 停止旧容器 → 启动新容器
5. 用户无感知，服务不中断（秒级重启）

## 手动更新（如果需要立即更新）

```bash
cd ~/tao-backend
docker compose pull backend
docker compose up -d backend
```

## 查看更新日志

```bash
# 查看 watchtower 日志
docker compose logs watchtower

# 查看 backend 日志
docker compose logs backend
```

## 回滚到旧版本

如果需要回滚到指定版本：

```bash
# 查看有哪些版本
# 去 https://github.com/cmj4088/TAO/pkgs/container/tao-backend 查看

# 拉取指定版本
docker pull ghcr.io/cmj4088/tao-backend:v0.1.0

# 修改 docker-compose.yml 中的 tag，或直接运行：
docker compose up -d backend
```

## 数据备份

数据库文件存在 `./data` 目录下（通过 volume 挂载），只要不删这个目录，数据就不会丢。

建议定期备份：
```bash
cp -r ~/tao-backend/data ~/tao-backend/backup-$(date +%Y%m%d)
```

## 防火墙设置

确保服务器防火墙开放 8002 端口：
```bash
# Linux (ufw)
sudo ufw allow 8002

# 云服务器还需要在安全组中放行 8002
```
