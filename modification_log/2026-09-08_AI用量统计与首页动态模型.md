# 追加（2026-09-08 20:40）：修复"记住我"不生效
- **需求**: 用户报 Bug"记住我并没有生效"（勾选后重启仍要重新登录）
- **根因（两处）**:
  1. `App.tsx` 路由表无根路径分流：Electron 启动加载 `app://index.html`（路径 `/`），命中 `*` 兜底无条件跳 `/login`——即使用户已登录也被带回登录页（主因）
  2. `client.ts` 刷新 token 时无条件写 localStorage——"不勾记住我"的用户 2 小时后也被悄悄持久化（选项两头都失效）
- **改动**:
  - 新增 `frontend/src/api/tokenStore.ts`：统一 token 存取层，持久化严格由 `remember_me` 标记控制
  - `authStore.ts`：login 记录记住我选择；读写全部走 tokenStore；register 保持默认持久化
  - `client.ts`：请求/响应拦截器改走 tokenStore
  - `App.tsx`：新增 `/` → `RootRedirect`（已登录进 /home，否则去 /login）
- **验证**: `tsc --noEmit` 通过；重打包 Setup 2.0.2.exe（20:40），asar 含 remember_me 标记
- **对应文件**: tokenStore.ts:1-71、authStore.ts:77-99、client.ts:12-21、App.tsx:26-29/88-91
- **归档**: tokenStore.ts.md（新建）、authStore.ts.md（新建）、App.tsx.md、client.ts.md（追加）
