教务办.智能体 — 总体架构需求
目标：为一所高校的教务办开发一款轻量级桌面控制台应用，集成了多个教务辅助工具（app01、app02…），即点即用，帮助教务办提升日常工作效率。

应用场景：
教务办工作人员打开桌面应用后，通过左侧导航栏切换到不同的子应用，在右侧工作区完成监考分配、文件审查等教务任务。管理员通过独立界面配置大模型 API。

功能：

1、控制台式主界面
    左侧导航栏列出所有子应用，点击切换，右侧显示对应界面。预留扩展位，新增 app 只需注册路由和菜单项。

2、子应用模块化
    每个 app 独立开发，有自己的界面、接口和状态。app01 做监考分配，app02 做文件审查，后续可加 app03、app04…

3、版本更新提醒
    右上角显示更新提示，检测到新版本时通知用户下载。

4、管理员配置界面
    独立入口，配置大模型的 URL 和 Key，所有子应用共用。

5、前后端分离
    前端用 Electron 做桌面客户端，后端用 FastAPI 提供接口，通过 HTTP 通信。

6、Docker 部署
    后端打成 Docker 镜像，一键启动。前端单独分发安装包。

7、工作断点续作
    关闭应用后重新打开，自动恢复上次的工作状态和结果。

痛点：
教务办老师日常要在多个工具间切换，效率低下。引入大模型后每个工具单独配 API 也很麻烦——需要一款统一入口、统一配置的桌面控制台。

技术栈建议：
桌面框架：Electron + React
后端框架：Python FastAPI
数据库：PostgreSQL 或 SQLite
部署：Docker + docker-compose
