教务办文件审查app
目标：为一所高校的教务办开发一款教务办文件审查应用，无需修改内容，仅需要标记错误文档。

应用场景：
教务办工作人员单个或批量上传学院老师的教学文件，然后和系统里面的模板文件进行比对，检查格式是否一致，有没有用规范的字体字号，从而来提高教务办工作人员的效率，最终向工作人员输出对应通过和不通过的文件，如不通过的文件需要给出具体的原因。
这里要求有两种模式，一种是单个文件审批，另外一种是批量审批

最基础功能1：
1、在界面点击app2子应用后，选择单文件的

功能2：
1、批量上传海量文件，
    以下是学校给三种文件的模板：
        [附件1：课程标准（体例）.doc](app02template/附件4：教学文件（课程标准、计划、教案）/附件4：教学文件（课程标准、计划、教案）模板/附件1：课程标准（体例）.doc)
        [附件2：学期授课计划表（体例）](app02template/附件4：教学文件（课程标准、计划、教案）/附件4：教学文件（课程标准、计划、教案）模板/附件2：学期授课计划表（体例）.doc)
        [附件3：教案（体例）.doc](app02template/附件4：教学文件（课程标准、计划、教案）/附件4：教学文件（课程标准、计划、教案）模板/附件3：教案（体例）.doc)
2、分析事实性错误
    比如：
        学校名字“深圳信息职业技术大学”写成“深圳信息职业技术学院”
        教师关键信息与文档内信息不匹配
        学时计算错误
3、调用API实现AI纠错
    AI需要完成的任务：
        查找并计算学时，在文档中检查对应课程安排学时是否符合逻辑，具体可以参考[课时上的事实性错误](app02template\课时上的事实性错误)
        记忆所有教师信息，在文档中筛查教师关键信息与文档内信息是否匹配，是否符合逻辑（如果一个文档里一个班级有两个课时安排，可能是班级填错）
        通过上下文语境识别错别字
4、规范字体
    当文档内出现超过5种字体就标记不合格
5、有汇总窗口
    在筛查后所有有错误的文件汇总到汇总窗口，文件名可直接点击查看，窗口遵循以下格式：
        |文件名|老师|教师编号|错误类型|错误位置|出现的问题（由AI总结）
6、导出有错误的名单
    以汇总窗口的格式导出excel表格
7、进度保存
    重新进入程序可以继续未完成的工作
8、文件审查 — 技术方案
    拿老师提交的文件和模板文件做对比，不一样的地方就标记出来。（这里的技术已经实现，在[document_content_extraction](document_content_extraction)）
        三步审查：
        1、格式检查
        - 把模板里的字体、字号提取出来，作为"合格标准"
        - 提交的文件如果用了模板没有的字体或字号，就标记为"格式偏离"
        - 比如模板只允许宋体，老师用了 Times New Roman，就会被发现

        2、课时计算检查
        - 从汇总表里读出"教学周数""周学时""总学时"
        - 验证：周数 × 周学时 是不是等于 总学时
        - 不相等就说明汇总表自己算错了

        3、课时一致性检查
        - 把进度表里每一行的学时加起来
        - 和汇总表声称的总学时做对比
        - 不一致就说明进度表和汇总表对不上

        关于 .doc 老格式：
        - 用 Word 的 COM 接口自动转成 .docx 再处理（仅限安装了 Word 的 Windows 电脑）

        审查结果输出：
        - 通过的标绿色，不通过的标红色
        - 不通过的文件要列出具体问题：哪个表格、哪个位置、偏离了什么
        - 支持导出汇总表格（文件名 + 老师 + 错误类型 + 位置 + 问题描述）
