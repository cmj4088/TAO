# 教务办·智能体 — 前后端启动说明

## 环境要求

- **Node.js** >= 18（前端 + Electron）
- **Python** >= 3.12（后端）
- 两个终端窗口，分别运行前端和后端

---

## 第一步：启动后端

打开终端，**先进入项目根目录，再进入 backend**：

```bash
cd C:\Users\32277\Desktop\TAO\backend
```

首次运行需安装 Python 依赖：

```bash
pip install -r requirements.txt
```

启动 FastAPI 服务：

```bash
uvicorn app.main:app --port 8000
```

看到 `Uvicorn running on http://127.0.0.1:8000` 说明后端已就绪。

验证：浏览器访问 `http://localhost:8000/api/version`，应返回 `{"version":"0.1.0"}`。

---

## 第二步：启动前端

再开一个终端，**先进入项目根目录，再进入 frontend**：

```bash
cd C:\Users\32277\Desktop\TAO\frontend
```

首次运行需安装 Node 依赖：

```bash
npm install
```

启动 Electron + Vite 开发环境：

```bash
npm run dev
```

等几秒 Vite 编译完成后，Electron 窗口会自动弹出，标题"教务办·智能体"。

> 如果只想在浏览器预览（不启动 Electron 窗口），用 `npm run dev:vite`，然后访问 `http://localhost:5173`。

---

## 常见问题

**Q: `cd backend` 找不到路径？**
你没有先进项目根目录。完整命令是 `cd C:\Users\32277\Desktop\TAO\backend`，注意前面有 `C:\Users\32277\Desktop\TAO\`。

**Q: Electron 窗口没弹出来？**
先确认 Vite 已启动（`http://localhost:5173` 能打开），再确认后端已启动（`http://localhost:8000/api/version` 有返回）。

**Q: 页面空白？**
打开浏览器开发者工具（Electron 窗口按 `Ctrl+Shift+I`），看 Console 是否有报错。

**Q: 后端报 `No module named 'app'`？**
确认当前在 `C:\Users\32277\Desktop\TAO\backend` 目录下，不是 `backend/app/`。

**Q: `npm install` 报错？**
Electron 二进制下载可能失败，试试 `npm install --ignore-scripts`。
