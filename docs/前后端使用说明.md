# 教务办·智能体 — 前后端启动说明

## 环境要求

- **Node.js** >= 18（前端 + Electron）
- **Python** >= 3.12（后端）
- 两个终端窗口，分别运行前端和后端

---

## 第一步：启动后端

打开终端，**先进入项目根目录，再进入 backend**：

```bash
cd C:\Users\32277\Desktop\TAO\backend
```

首次运行需安装 Python 依赖：

```bash
pip install -r requirements.txt
```

启动 FastAPI 服务：

```bash
uvicorn app.main:app --port 8001
```

看到 `Uvicorn running on http://0.0.0.0:8001` 说明后端已就绪。

验证：浏览器访问 `http://localhost:8001/api/version`，应返回 `{"version":"0.1.0"}`。

> 端口默认用 8001。如果端口被占用，改 `--port` 参数，同时改 `frontend/src/api/client.ts` 里的 `API_BASE`。

---

## 第二步：启动前端

再开一个终端，**先进入项目根目录，再进入 frontend**：

```bash
cd C:\Users\32277\Desktop\TAO\frontend
```

首次运行需安装 Node 依赖：

```bash
npm install
```

启动 Electron + Vite 开发环境：

```bash
npm run dev
```

等几秒 Vite 编译完成后，Electron 窗口会自动弹出，标题"教务办·智能体"。

> 如果只想在浏览器预览（不启动 Electron 窗口），用 `npm run dev:vite`，然后访问 `http://localhost:5173`。

## app02 文件审查使用流程

### 1. 导入文件

- 拖拽 `.doc` / `.docx` 文件或文件夹到上传区，或点击"选择文件"/"选择文件夹"
- 导入成功后弹出提示"已接收 N 个文件"，上传区下方显示文件标签列表
- **支持累加导入**：审完一批后可以继续拖入更多文件，不会清空已有文件

### 2. 开始审查

点击「开始审查」按钮，系统分两阶段自动执行：

- **第一阶段：格式检查** — 对比模板，检查字体、字号、对齐方式、字体数量
- **第二阶段：AI 审查** — 自动启动（无需手动点），逐一分析每个文件：
  - 学校名称错误（"深圳信息职业技术学院" → 应为"深圳信息职业技术大学"）
  - 教师信息不匹配
  - 错别字
  - 课时计算错误（周数 × 周学时 = 总学时，考虑假期扣减）
  - 课时不一致（进度表累加 vs 汇总表）
  - 自动提取教师姓名、课程名称、班级名称

### 3. 审查进度

- 每个文件左侧有状态指示器：
  - 🔵 蓝色脉冲动画 = AI 正在审查这个文件
  - ⚪ 空心圈 = 排队等待中
  - 🔴 红叉 = 有问题需要修改
  - 🟢 绿勾 = 审查通过
- 顶部有 AI 审查进度条，显示当前审查的文件名和进度（N/总数）

### 4. 审查结果

- 结果以**文件卡片列表**展示，点击卡片可展开查看详细问题
- 右上角 Segmented 控件切换「需修改」和「全部」视图
- 每个问题显示类型标签、详细描述、位置、修改建议
- AI 发现的问题带紫色 `AI` 标签
- 关键错误（红色）排前面，提醒建议（黄色）排后面
- 「需修改」模式下只显示关键错误

### 5. 忽略误报

- 每个关键错误右侧有「忽略」按钮
- 点击后问题变灰 + 删除线，不计入"需修改"
- 文件所有关键错误都被忽略后，状态自动变为"通过"
- 可以「取消忽略」恢复

### 6. 复制与导出

- 展开卡片后可「仅复制关键错误」或「复制全部（含提醒）」
- 点击「导出 Excel」下载汇总表格

### 7. 追加文件

审查过一次后，上传区仍然可见，可以继续导入更多文件。按钮会变为「审批新增」——只审查新文件，已审过的文件保留结果不变。

### 8. 查看原文

点击卡片上的「查看原文」按钮，在右侧打开新标签页，左侧是 PDF 预览，右侧是错误批注。

## 常见问题

**Q: `cd backend` 找不到路径？**
你没有先进项目根目录。完整命令是 `cd C:\Users\32277\Desktop\TAO\backend`。

**Q: Electron 窗口没弹出来？**
先确认 Vite 已启动（`http://localhost:5173` 能打开），再确认后端已启动（`http://localhost:8001/api/version` 有返回）。

**Q: 页面空白？**
打开浏览器开发者工具（Electron 窗口按 `Ctrl+Shift+I`），看 Console 是否有报错。

**Q: 后端报 `No module named 'app'`？**
确认当前在 `C:\Users\32277\Desktop\TAO\backend` 目录下，不是 `backend/app/`。

**Q: `npm install` 报错？**
Electron 二进制下载可能失败，试试 `npm install --ignore-scripts`。

**Q: 点击「开始审查」后没有看到 AI 进度？**
检查后端终端是否有报错日志。常见原因：API key 在 `ai_reviewer_app02.py` 中硬编码的 `ARK_KEY` 过期或被禁用。
