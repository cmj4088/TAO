# skill/ — 项目专用 Skills

此目录存放项目暂时使用的 Claude Code Skills。

## 使用方式

在 Claude Code 对话中，通过 `/skill-name` 或引用 skill 文件来使用。

## 当前 Skills

暂无。需要添加的 skill 请在此目录下创建对应的 `.md` 文件。

## 建议添加的 Skills

1. **code-review** — 代码审查（已有内置 skill）
2. **verify** — 验证代码变更（已有内置 skill）
3. **simplify** — 代码简化/重构（已有内置 skill）
4. 项目特定的 skill（如监考分配算法测试、文档审查流程验证等）
